# SSE 实时推送（2026-08-25）

## 背景

用户实测反馈：网页每 1 秒轮询一次太慢，不如终端实时显示最近输出直观。预期：
1. 网页显示像终端那样（逐段实时，不是 1 秒蹦一大段）；
2. 看最新的不用徒手翻滚动条；
3. 看前面历史时不被新内容刷屏，但输出照样更新。

拆成两个独立问题：
- 问题 A（实时性）：web 固定 `setInterval(tick, 1000)` 轮询，agent 端思考 delta 到达即写文件/打印（终端逐字），网页每 1 秒才读一次 → 思考文本每 1s 蹦一大段。
- 问题 B（滚动）：`#timeline` 容器 max-height 460px 无自动滚动，看最新要手动拉；期望智能跟随。

## 决策过程

- 问题 B 定智能跟随滚动：容器距底 < 40px 时自动滚到底；滚离底部暂停跟随；滚回底部恢复。
- 问题 A 先做 A1（轮询 1s→200ms + 图片按需刷新），用户实测后**直接改为 SSE**（跳过 A1 实际验证）。

## 实施（agent.py + web/index.html）

### 后端（agent.py）

- `/events` SSE 端点：`_Handler.do_GET` 特判，`_serve_sse()` 返回 `text/event-stream` 长连接。
- `_Handler.protocol_version = "HTTP/1.1"`（SSE 长连接必需；静态响应均有 Content-Length，兼容连接复用，selftest 全过验证无破坏）。
- 连接管理：每连接一个 `queue.Queue` + 专属线程阻塞消费（`q.get(timeout=15)`，空闲发 `: heartbeat` 注释行心跳）；`_sse_broadcast(event, data)` 广播前 `get_nowait()` 丢弃旧事件只留最新（快照语义，中间版本丢弃无妨）。
- `_Server.daemon_threads = True`：SSE 长连接线程非守护会阻塞进程退出（main 结束后脚本挂住）。
- 广播点：
  - `write_reasoning_live` → `reasoning` 事件 `{round, reasoning}`（思考全文，json 序列化换行转义为 `\n`，SSE data 行安全）；
  - `clear_reasoning_live` → `reasoning` 事件 `{round: -1}`；
  - `snap()`（包装 `xor_world.snapshot` + `_sse_broadcast("state", xor_world.state)`）→ `state` 事件，main 中 5 处 snapshot 调用全部替换。
- 浏览器关闭/刷新连接写失败（OSError）→ break 移除连接，不影响主循环。

### 前端（web/index.html）

- 主通道 `EventSource('/events')`：`reasoning` 事件更新 liveRound/liveText，`state` 事件更新 lastState 并渲染；渲染经 `requestAnimationFrame` 合并（delta 频率 > 60fps 时只渲染最新状态）。
- 兜底 `setInterval(tick, 3000)` 低频轮询（EventSource 断线自动重连，重连间隙靠轮询保证最终一致）；页面加载 tick() 拉一次全量（SSE 无历史事件）。`refresh()` 同步更新 lastState。
- 智能跟随滚动（距底 < 40px）+ 图片按快照名去重刷新（上一步 A1 改动保留）。

## 验证（probe_sse.py，不需要 API key，已删）

链路：`/events` 200 + text/event-stream → `write_reasoning_live` 推 reasoning（含换行转义）→ `snap` 推 state（含 grid/status/image）→ `clear_reasoning_live` 推 round=-1。全部通过。

```python
"""验证 SSE 实时推送链路（不需要 API key）：
1. GET /events 返回 200 + text/event-stream
2. write_reasoning_live → 收到 reasoning 事件（round + 思考全文，含换行）
3. snap → 收到 state 事件（grid/image/status）
4. clear_reasoning_live → 收到 reasoning round=-1 事件
"""
import http.client
import socket
import threading
import time

import agent
import xor_world

httpd, port = agent.start_server(agent.BASE, 0)
print(f"[0] server port={port}")

conn = http.client.HTTPConnection("127.0.0.1", port, timeout=3)
conn.request("GET", "/events")
resp = conn.getresponse()
print(f"[1] /events status={resp.status} content-type={resp.getheader('Content-Type')}")
assert resp.status == 200
assert resp.getheader("Content-Type", "").startswith("text/event-stream")


def push():
    time.sleep(0.3)
    agent.write_reasoning_live(1, "第一段思考")
    time.sleep(0.2)
    agent.write_reasoning_live(1, "第一段思考\n第二段思考")
    time.sleep(0.2)
    xor_world.init(seed_value=5, seed_index=0)
    agent.snap(0)
    time.sleep(0.2)
    agent.clear_reasoning_live()


t = threading.Thread(target=push)
t.start()
body = b""
try:
    while True:
        chunk = resp.read1(65536)
        if not chunk:
            break
        body += chunk
        if b"event: state" in body and b'"round": -1' in body:
            break
except socket.timeout:
    pass
t.join()
conn.close()
httpd.shutdown()

print(f"[2] 收到原始流:\n{body.decode('utf-8')!r}")
assert b"event: reasoning" in body, "缺 reasoning 事件"
assert "第一段思考\\n第二段思考".encode("utf-8") in body, "思考全文（含转义换行）未完整推送"
assert b"event: state" in body, "缺 state 事件"
assert b'"status": "running"' in body, "state 事件缺状态"
assert b'"round": -1' in body, "缺 clear 事件"
print("[3] SSE 链路验证通过 OK")
```

实测输出（节选）：`[1] /events status=200 content-type=text/event-stream; charset=utf-8`；`[3] SSE 链路验证通过 OK`。

探针踩坑：SSE data 行内换行会被 json.dumps 转义为 `\n` 字面量（不是裸换行字节），断言需匹配转义后文本；bytes 断言要写 `b"..."` 而非 str。
