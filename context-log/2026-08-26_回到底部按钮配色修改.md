# 2026-08-26「回到底部」按钮配色修改

创建时间: 2026-08-26
来源: 待修问题清单（2026-08-25_待修问题清单.md 第 8 条）

## 问题描述

- 现象：「回到底部」按钮深绿底（`#2a7`，rgb 34,170,119）与思考文字浅绿（`.why` `#8c8`，rgb 136,204,136）同为绿色系，扫一眼难以区分按钮和文本。
- 违反设计原则：意符清晰可感知（AGENTS.md 设计原则：不同类型的 UI 控件，避免使用难以区分的颜色/样式）。

## 根因分析

- 按钮背景 `#2a7` 与思考文字 `#8c8` 色相相近（都是绿色系），虽然一个色块一个文字、明度不同，但快速扫视时仍易混淆。
- 页面已有蓝（组头 `.ghead` `#9cf`）、橙（状态 `#status` / 格值 `.cell b` `#fc9`）两个强调色可用，按钮只需离开绿色系即可区分。

## 候选方案

| 方案 | 底色 | hover | 文字 | 特点 |
|------|------|-------|------|------|
| A | `#9cf` 浅蓝 | `#adf` | 黑字 `#0a0a0a` | 与组头一致 |
| B | `#fc9` 浅橙 | `#fd6` | 黑字 `#0a0a0a` | 与状态/格值一致 |
| C | `#36c` 深蓝 | `#48d` | 白字 `#fff` | 新增，比浅蓝更醒目 |
| D | `#666` 中性灰 | `#888` | 白字 `#fff` | 不抢强调色 |

对比度：A/B 浅底黑字约 13:1+；C 深蓝白字约 4.8:1；D 灰底白字约 5:1（12px 小字 AA 达标）。

## 测试方式（用户选定：页面内循环换色）

临时在 index.html 加了 3 处，浏览器实测比较后删除：

1. **CSS 变量接管**（#follow-btn 的 background/color/hover 改为 `var(--fb-bg, #2a7)` 等，默认值不变，不按键时行为与原一致）；
2. **临时提示条** `<div id="theme-tip">`（fixed 右上角，显示当前方案与色值）；
3. **临时 JS**（按 `C` 键循环切换 4 个配色，通过 `style.setProperty` 设置 CSS 变量，hover 跟随变化）。

不占用按钮本身点击（点击仍是回到底部），测试完清理无残留。

## 测试结果

用户浏览器实测（sim_agent.py 回放驱动 UI）：选方案 A（蓝），但认为 `#9cf` 偏白、亮了一点，微调为 `#9bf`（更偏蓝）。

## 敲定方案

- 按钮背景 `#9bf`（rgb 153,187,255，比 `#9cf` 少绿多蓝），文字黑 `#0a0a0a`，hover `#acf`。
- 决策依据：蓝色与思考绿 `#8c8` 色相差大（绿→蓝约 60°+），一眼可区分；与组头蓝 `#9cf` 同色系保持页面一致；`#9bf` 比 `#9cf` 更蓝，与组头浅蓝仍可区分（按钮是色块+固定位置，不混淆）。

## 临时测试代码存档（防丢失）

测试用循环换色 JS（2026-08-26 测试后已删除，此处留档）：

```js
const FOLLOW_THEMES = [
  { name: 'A 蓝(组头)', bg: '#9cf', hover: '#adf', color: '#0a0a0a' },
  { name: 'B 橙(状态)', bg: '#fc9', hover: '#fd6', color: '#0a0a0a' },
  { name: 'C 深蓝', bg: '#36c', hover: '#48d', color: '#fff' },
  { name: 'D 中性灰', bg: '#666', hover: '#888', color: '#fff' },
];
let followTheme = -1;
function applyFollowTheme(i) {
  followTheme = i;
  const b = $('follow-btn');
  b.style.setProperty('--fb-bg', FOLLOW_THEMES[i].bg);
  b.style.setProperty('--fb-hover', FOLLOW_THEMES[i].hover);
  b.style.setProperty('--fb-color', FOLLOW_THEMES[i].color);
  $('theme-tip').textContent = '配色测试 ' + FOLLOW_THEMES[i].name + ' (' + FOLLOW_THEMES[i].bg + ') · 按 C 换下一个 · 先向上翻历史使按钮浮现';
}
document.addEventListener('keydown', e => {
  if (e.key.toLowerCase() === 'c' && !e.ctrlKey && !e.altKey && !e.metaKey) {
    applyFollowTheme((followTheme + 1) % FOLLOW_THEMES.length);
  }
});
applyFollowTheme(0);
```

配套 CSS（临时）：`#follow-btn` 的 background/color/hover 分别改为 `var(--fb-bg, #2a7)` / `var(--fb-color, #0a0a0a)` / `var(--fb-hover, #3c9)`；提示条 `<div id="theme-tip" style="position:fixed;top:8px;right:8px;...">` 置于 h1 后。

## 可复用经验

- **UI 配色对比测试**：不改交互入口（按钮点击已有功能），用键盘快捷键循环切换 CSS 变量实现多方案同屏比较；CSS 变量默认值保留原色，不按键时行为与原来完全一致，安全。
- 与思考文字（绿）区分：选与页面已有强调色同系（蓝/橙）且色相差大的颜色，保持页面整体一致的同时避免同色相混淆。
