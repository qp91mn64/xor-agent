## 已核实的公式（探针验证，128 值全一致）

白像素占比只取决于 mask 的二进制 1 个数 k（probe_popcount_ratio.py，暴力遍历对照）：

- a ≥ 0：ratio = (64 − 2^(6−k)) / 64
- a < 0：mask = −a−1，ratio = 1 − (64 − 2^(6−k)) / 64（反色取补）

原理：每个 dy 行 dx^dy 是 0..63 的一个置换；mask 置位的 k 位约束 `(dx^dy)&mask==0` 恰有 2^(6−k) 个值。
含义（灰度方案的固有局限）：a=1/2/8/16/32 占比都是 0.5，但图案结构完全不同——灰度只编码"亮度"，不编码"结构"。

## 缩略图 2×2 下采样的核实

- 前端 thumb 分支**已经是 2×2 平均**（probe_thumb_2x2.py 全部 128 值一致，仅 5 档量化差），用户最初怀疑是别的方法，已澄清。
- 2× 下采样的固有损失（不是 bug）：1px 棋盘平均成灰面；2px 条纹按相位整条消失（如值 42 的 bit1 条纹消失，只剩 8px/32px 结构）。

## 四个模式与测试结果

### 模式 0 热力图（现状，基线）
色相=值，低红高蓝。代码未变。

### 模式 1 灰度=白像素占比（候选，未动）
- 灰 = ratio×255，文字黑/白随底明暗（灰>127 黑字），种子边框同理。
- 优势：简洁、语义自明（亮格=亮图案）、公式精确。不足：区分度有限（见公式核实）。

### 模式 2 缩略图(b)：黑白细节 + 文字局部亮度自适应 —— **用户已排除**
- 2×2 平均黑白缩略图；文字颜色取"文字下方局部小区域"平均亮度（>2/4 白 → 黑字）。
- 排除原因：不如模式 3 直观（用户原话"不如…直观"）。

### 模式 3 缩略图(c)：黑纹191灰 / 白纹64深灰 + 符号定文字色 —— **更直观，但细节丢失严重**
- 映射：a≥0 → 2×2 全黑块(w=0)变 191 灰、其余变 255 白，黑字；a<0 → 全白块(w=4)变 64 深灰、其余变 0 黑，白字。
- 用户实测（截图用 Windows 画图打开、填充颜色确认）：**-64，-16，-8，-4，-2，11，21，27，31，43，63 的格子连成一片，非文字部分无图案细节**。
- 根因（本次分析）：上述值的 mask 都含 bit0，而 bit0=δx^δy 在每个 2×2 块内取 0/1 各半 → 块内必有白像素 → 正值侧 w 永不为 0 → 全格映射 255 白；负值侧 w 永不为 4 → 全格映射 0 黑。二值映射把"块内有无白"整块吞并：
  - a=11（bits 0,1,3）→ 全格白；a=-2（mask=1）→ 全格黑；a=-64（mask=63）→ 主对角线附近 w=1 的块也被映射 0 → 全格黑。

## 探针脚本存档（防丢失）

两个探针已跑通并用于核实公式与下采样，定稿后删除：

- `probe_popcount_ratio.py`：白像素占比公式 vs 暴力遍历（128 值全部一致）。
- `probe_thumb_2x2.py`：前端缩略图逻辑 == 真 2×2 平均（128 值一致）；并打印 11/27/43/59 区域缩略图 ASCII 供对照。

probe_popcount_ratio.py：

```python
"""探针：验证「白像素占比 = f(popcount)」公式（值域 [-64,63]，图案 64x64，(dx^dy)&mask 渲染）。"""
def popcount(x): return bin(x).count('1')
def brute(a):
    mask = a if a >= 0 else -a - 1
    invert = a < 0
    white = 0
    for dy in range(64):
        for dx in range(64):
            w = ((dx ^ dy) & mask) != 0
            if w != invert: white += 1
    return white / 4096
def formula(a):
    m = a if a >= 0 else -a - 1
    k = popcount(m)
    base = (64 - (1 << (6 - k))) / 64
    return base if a >= 0 else 1 - base
bad = [(a, brute(a), formula(a)) for a in range(-64, 64) if abs(brute(a) - formula(a)) > 1e-12]
print("全部一致" if not bad else f"不一致: {bad}")
```

probe_thumb_2x2.py（核心校验逻辑）：

```python
def js_thumb(a):   # 复刻前端 drawParamGrid thumb 分支
    mask = a if a >= 0 else -a - 1
    invert = a < 0
    out = []
    for py in range(32):
        row = []
        for px in range(32):
            w = 0
            for dy in range(py * 2, py * 2 + 2):
                for dx in range(px * 2, px * 2 + 2):
                    if ((((dx ^ dy) & mask) != 0) != invert): w += 1
            row.append(round(w * 63.75))
        out.append(row)
    return out

def true_2x2(a):   # 真 2×2 平均（不量化）
    mask = a if a >= 0 else -a - 1
    invert = a < 0
    out = []
    for py in range(32):
        row = []
        for px in range(32):
            w = 0
            for dy in range(py * 2, py * 2 + 2):
                for dx in range(px * 2, px * 2 + 2):
                    white = ((dx ^ dy) & mask) != 0
                    if white != invert: w += 1
            row.append(w * 255 / 4)
        out.append(row)
    return out
# 128 值逐像素比较 |js-thumb - true| <= 32（5 档量化差）→ 全部通过
```
