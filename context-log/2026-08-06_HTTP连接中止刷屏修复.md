# HTTP 连接中止刷屏修复

日期：2026-08-06

## 现象

真实运行（xor_agent_20260806_221032.log 期间）终端出现多处：
```
Exception occurred during processing of request from ('127.0.0.1', 61482)
... ConnectionAbortedError: [WinError 10053] 你的主机中的软件中止了一个已建立的连接。
```

## 原因

- web 页面轮询 `/output/` 下文件（state.json/快照等），页面关闭、刷新或导航时，在途请求被浏览器中止；
- `SimpleHTTPRequestHandler` 的 `copyfile` → `sendall` 抛 `ConnectionAbortedError`（Windows WinError 10053，还有 10054 ConnectionReset / BrokenPipe）；
- `socketserver.ThreadingTCPServer` 默认 `handle_error` 把完整 traceback 打到 stderr → 刷屏。

## 修复

`_Server.handle_error` 覆盖：连接中止类异常静默，其余仍默认打印（防止掩盖真错误）：
```python
def handle_error(self, request, client_address):
    exc = sys.exc_info()[1]
    if isinstance(exc, (ConnectionAbortedError, ConnectionResetError, BrokenPipeError)):
        return
    super().handle_error(request, client_address)
```

## 验证

- 直接调用 `handle_error`：抛 `ConnectionAbortedError` → stderr 输出长度 0；抛 `ValueError` → 仍打印（True）。
- socket 冒烟测试：请求后立即关闭连接，无 traceback 输出。
