# 运行产物按运行分文件夹（state.json 历史不覆盖）

> 2026-09-01。决策 + 实现记录。

## 面对的问题和需求

`output/state.json` 每次运行都覆盖写同一个文件，旧运行结果被冲掉。需求：每次运行在 `output/` 下按时间戳建独立文件夹放运行产物，历史运行不被覆盖。

## 提出的各方案

1. **A：分钟精度时间戳 + 冲突加字母**：`202609010723` → `202609010723a` → `202609010723b`
   - 优势：文件夹名直接可读时间；字典序 = 时间序永远成立（字母后缀 > 无后缀，如 `202609010723a` > `202609010723`）；后缀只在同分钟二次启动时出现。
   - 不足：名字长短不一；z 之后需定义（继续 aa…，实际达不到）。
2. **B：日期 + 字母序列**：`20260901a` … `20260901z` → `20260901aa`
   - 隐藏坑：**过 z 后字典序不再等于时间序**——`20260901aa` < `20260901b`（'a'<'b'），但 aa 后创建。文件资源管理器排序、将来"取最新运行"按名字取最大都会错乱。
   - 且名字看不出当天几点跑的。
3. **A 变体：秒精度**（敲定）：`20260901_072315`，与日志命名 `xor_agent_20260901_072315.log` 同款时间戳段。同秒启动才可能撞，字母后缀纯属兜底。
4. 前缀问题（用户追问"开头要不要加 output_"）：不加。文件夹已在 `output/` 里，`output/output_...` 语义重复；区分"运行文件夹 vs 其他文件"用正则 `^\d{8}_\d{6}` 即可，不靠前缀。

## 关键架构约束（任何方案都躲不掉）

web 前端固定轮询两个 URL（web/index.html）：`/output/state.json` 与 `/output/reasoning_live.json`。方案实现时必须在 HTTP 层把这两个固定 URL 映射到**当前运行文件夹**（进程内指针 RUN_ID，比扫描目录取最新可靠），前端一行不用改。

## 敲定的方案

- `init_run_dir()`：启动时（main 与 sim_agent 回放均走此函数）创建 `output/<%Y%m%d_%H%M%S>/`，同秒冲突 `os.mkdir` 原子创建 + `FileExistsError` 后 `_next_letter` 递增重试（"" → a → … → z → aa → ab…，双射 base-26）——两个进程同秒启动也各拿唯一文件夹。
- `state.json`（每次工具调用后覆盖写本运行文件夹内）与 `reasoning_live.json` 都在运行文件夹内；`output/` 根目录不落任何实时文件，只含各次运行文件夹。
- HTTP `do_GET`：`/output/state.json`、`/output/reasoning_live.json` 在 RUN_ID 建立后改写为 `/output/<RUN_ID>/<同名文件>`，白名单检查照旧；RUN_ID 未建立时走白名单 → output/ 根无该文件 → 404（等价"运行尚未开始"）。
- 日志 `xor_agent_*.log` 不挪进运行文件夹（用户决定），仍在项目根。
- selftest：快照断言改用 `agent.init_run_dir()`；测试结束 `shutil.rmtree` 清理自己创建的运行文件夹（output/ 只留真实运行存档）。

## 测试

- `python tests/selftest.py`：全过（快照 OK: output/<时间戳>/state.json；HTTP /output/state.json 200；白名单外 404 回归）。
- 探针 `probe_run_dir.py`（用完即删）：`_next_letter` 序列 a…z,aa,ab；预建同名文件夹 → 同秒冲突新建 `xxxa`；进程内幂等。全过。
- 探针 `probe_http_map.py`（用完即删）：state.json 映射 200；reasoning_live 存在时 200、清理后 404；白名单外 404 回归。全过。
- `python tests/sim_agent.py --dry-run`：导入 + 解析正常（sim_agent 用 agent.snap/write_reasoning_live，自动跟随新文件夹机制，无需改）。

## 经验

- 命名对比不能只看"是否能区分"，要看**排序语义是否等于时间语义**（B 方案的 aa 坑就是反例）。
- 实时轮询场景，历史归档与"固定 URL 拿当前值"可以兼得：HTTP 层映射，前端零改动。
- 临时探针验证后即删，代码（含测试）先跑通再交付。
