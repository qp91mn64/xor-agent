# 实时思考面板空 UI 根因与修复（2026-08-23）

## 现象（用户实测）
- web 的「实时思考（流式）」卡片：标题+边框常驻，内容区一直空白，无文字。
- AI 思考内容最终一次性显示在「AI 点击轨迹」卡里（每轮分组带"思考: ..."），不是逐行流式出现。
- 命令行能实时打印思考（2026-08-05 已实测），web 实时卡却始终空。

## 根因（前端 bug，非数据链路问题）
1. **`#live-box` 永不可见**：`web/index.html` CSS 中 `#live-box { display: none; }`，
   JS `refreshLive` 在 fetch 成功时只写 `style.display = ''`（空字符串 = 删除内联样式，
   回退到 CSS 默认值 `none`）→ 内容区**永远隐藏**。所以即使 `reasoning_live.json` 有内容，实时卡也永远是空框。
2. **「一次显示完」**：拿到全文后 `textContent = 全文` 一次性赋值，无逐行/逐段节奏。

## 验证（探针实测，不需要 API key）
`probe_live_chain.py`（见文末代码）结果：
- 写文件后 `GET /output/reasoning_live.json` → 200，内容为最新覆盖版本
- `clear_reasoning_live()` 删除后 → 404（web 据此显示占位）
- mock 增量流式 chunk 完整跑 `chat_stream` → 文件内容 = 累积全文
- 结论：**后端写文件 + HTTP 暴露 + 删除隐藏的链路全部正常**，问题只在前端 display 逻辑。

## 修复（web/index.html）
1. CSS 去掉 `#live-box { display: none; }` → 面板常驻可见。
2. `refreshLive` 重写：
   - 文件不存在（404/异常）→ 显示占位「（等待本轮思考…）」，不再隐藏面板。
   - 文件存在 → 打字机逐段放出：`LIVE_TICK=60` 字符/秒，`round` 变化时重置从头放。
   - 兼容两种情况：API 增量返回（轮询拿到变长全文，打字机追赶）与一次性返回（前端模拟逐行）。
3. 初始 HTML 内容区放入占位文案。

## 探针代码（probe_live_chain.py）
```python
"""验证 reasoning_live 链路（不需要 API key）：
1. write_reasoning_live 在 Windows 上能否成功写文件（os.replace 覆盖）
2. HTTP 服务能否正确暴露 /output/reasoning_live.json
3. 文件删除后是否 404（web 据此隐藏面板）
4. mock 流式增量 chunk 完整跑 chat_stream，结束后文件内容应等于全文
"""
import os, time, urllib.request, urllib.error
import agent
from types import SimpleNamespace

def fetch(path):
    try:
        with urllib.request.urlopen(f"http://127.0.0.1:{port}{path}", timeout=3) as r:
            return r.status, r.read().decode("utf-8")
    except urllib.error.HTTPError as e:
        return e.code, ""

agent.write_reasoning_live(1, "第1行思考")
agent.write_reasoning_live(1, "第1行思考\n第2行思考")
httpd, port = agent.start_server(os.path.abspath("."), 0)
time.sleep(0.2)
try:
    st, body = fetch("/output/reasoning_live.json")
    print(f"[1] 写文件后 fetch: status={st} body={body!r}")
    assert st == 200 and "第2行思考" in body
    agent.clear_reasoning_live()
    st, _ = fetch("/output/reasoning_live.json")
    print(f"[2] 删除文件后 fetch: status={st}")
    assert st == 404
    def mk_chunk(reasoning=""):
        delta = SimpleNamespace(reasoning_content=reasoning or None, content=None, tool_calls=None)
        return SimpleNamespace(choices=[SimpleNamespace(delta=delta)])
    chunks = [mk_chunk("思考第"), mk_chunk("一段。"), mk_chunk("思考第"), mk_chunk("二段。")]
    class FakeCompletions:
        def create(self, model, messages, tools, stream):
            return iter(chunks)
    class FakeChat: completions = FakeCompletions()
    class FakeClient: chat = FakeChat()
    msg = agent.chat_stream(FakeClient(), [], 1)
    assert msg.reasoning_content == "思考第一段。思考第二段。"
    st, body = fetch("/output/reasoning_live.json")
    assert st == 200 and '"思考第一段。思考第二段。"' in body
    print("链路验证全部通过 OK")
finally:
    agent.clear_reasoning_live()
    httpd.shutdown()
```
实测输出：`[1] status=200`；`[2] status=404`；`[3] 跑完后 status=200 body=全文`；链路验证全部通过 OK。
